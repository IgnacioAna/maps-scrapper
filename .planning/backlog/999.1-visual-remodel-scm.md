# 999.1 — Visual Remodel SCM (Sales Closing Machine)

> **Status**: Backlog. Capturado 2026-05-23.
> **Trigger sugerido**: cuando el sistema tenga ≥3 setters operativos en producción Y haya feedback acumulado de al menos 2 semanas de uso real.
> **Effort estimado**: 16-24h.
> **Predecesor**: Sprint 15 ya hizo un mini-rediseño (login + sidebar branding + identidad inicial "Sales Closing Machine"). Esta phase es la remodelación completa.

---

## Por qué

El SCM se llama "Sales Closing Machine" pero hoy la estética es la de un CRM dental neutral genérico. El nombre promete **una máquina diseñada para cerrar deals**, y el visual tiene que reflejarlo:

- **Energía visual de tablero industrial elegante**: precisión, velocidad, datos prominentes
- **Sin distracciones**: cada pixel sirve al cierre
- **Para equipo de alto rendimiento**: el setter siente que es una herramienta seria, no un Excel con UI

Hoy hay zonas que se ven amateur:
- Centro de Comando (admin) — stat cards genéricas, sin jerarquía
- View "Setteo (WhatsApp)" — la principal de los setters, está saturada
- Banco de Respuestas — usable pero estéticamente flat
- Mercury Review — funcional pero árido
- Onboarding — moderno pero desconectado del resto del sistema

---

## Decisiones gray-area pendientes (resolver en discuss-phase)

1. **¿Rebranding del logo?** Hoy es "S" en violeta. ¿Mantener o evolucionar hacia algo con más identidad (un logotipo, monograma)?
2. **¿Paleta única o dark mode + light mode?** Hoy solo dark. ¿Vale la pena light?
3. **¿Animaciones?** Hoy mínimas. ¿Microinteracciones tipo Linear/Vercel? Cuidar performance.
4. **¿Componentes adicionales o solo CSS?** ¿Vale la pena introducir un design system framework (shadcn/ui port, etc.) o quedarse con vanilla?
5. **¿Tipografía?** Hoy Geist. ¿Pareja con un display font para titulares?
6. **¿Iconografía?** Hoy emojis 😅 mezclados con SVG inline. Unificar a un set (Lucide, Heroicons, Tabler).
7. **¿Mobile responsive serio o solo desktop?** Setters van a usar laptop principalmente, pero admin podría querer mirar stats del celu.
8. **¿Sonidos?** Speed-to-lead ya beep. ¿Sonidos para cierre agendado, lead nuevo, alertas?

## Scope sugerido

### Sprint A — Design System Foundation (4-6h)
- Tokens CSS reorganizados (colors, spacing, typography, shadows, radii) en archivo dedicado
- Componentes reutilizables documentados: Button, Card, Modal, Tabs, Toast, Stat, Badge, Input
- Storybook estático o página interna `/design-system` con todos los componentes
- Define brand voice visual (icon set único, microcopy patterns)

### Sprint B — Rediseño view-crm (Setteo WhatsApp) (4-6h)
La vista MÁS usada por setters. Hoy se siente saturada.
- Reorganizar zona de filtros (chips collapsable)
- Lead card rediseñada (info denso pero respirable)
- Acciones rápidas más prominentes (botones de envío)
- Variantes A/B visibles sin sobrecargar
- Métricas en vivo más limpias

### Sprint C — Rediseño Centro de Comando (admin) (3-4h)
La vista del dueño. Tiene que sentirse "tablero del piloto".
- Hero metrics arriba (3-5 KPIs core)
- Dashboard de equipo con avatars y semáforos
- Sparklines o gráficos Chart.js mejorados
- Sección "atención inmediata" (alertas, pendientes)

### Sprint D — Rediseño Llamadas + Centralita Telnyx (3-4h)
Ya tiene buena estructura post-Sprint 4-14, pero refinar:
- Cards de número virtual estilo "SIM card" visual
- Routing por país con mapa miniatura (opcional)
- Mejor heatmap horario (Sprint 9 stat)
- Panel de llamada full-screen mode opcional

### Sprint E — Microcopy + Empty States (2-3h)
- Cada empty state con personalidad SCM (no "No hay datos" genérico)
- Toasts con copy más específico
- Labels y placeholders más human
- Tooltips útiles en cada campo

### Sprint F — Onboarding visual (2h)
Hoy los 8 módulos del onboarding tienen su propio CSS embedded. Alinear estética con el resto del sistema. Quiz panel rediseñado.

## Material externo que sería útil para acelerar esta phase

Cuando esta phase se active, podés pasarme:

1. **Screenshots de CRMs que te gustan visualmente** — específicamente sales-focused: Apollo, Close.io, Pipedrive, HubSpot Sales Hub, Salesloft. Aunque sea 1 screenshot de cada uno con flecha mostrando qué te gusta.

2. **Moodboard / Pinterest** — referencias estéticas que te inspiran (no necesariamente CRMs — pueden ser dashboards de trading tipo Bloomberg, paneles tipo Linear/Vercel, apps tipo Superhuman).

3. **Marca propia** — si tenés logo de SCM Dental o ALLAWANNA LLC, mandalo. Colores corporativos, fuentes corporativas si están definidas.

4. **Lista de pantallas que más usás** — qué view ves 50 veces por día vs cuál ves 1 vez por semana. Eso ordena prioridades de rediseño.

5. **Feedback acumulado de setters** — quejas concretas tipo "no encuentro el botón X", "esta zona es confusa", "esto siempre lo cierro sin querer". Esos son los puntos donde más impacta UX.

6. **Caso de uso real de pantallazo** — pasame screenshots de los momentos donde te sentís incómodo usando el SCM. Tipo: "acá en este modal me bloqueo siempre".

7. **Estética target** — si querés un look específico (minimalista, brutalist, glassmorphism, neumorphism, neobrutalism) decílo. Si no sabés, te muestro ejemplos.

8. **Audio brand** — si va a tener sonidos (beep para alerts, "ding" para agenda cerrada), podés grabar/elegir cuáles.

9. **Iconografía preferida** — opciones libres: Lucide, Heroicons, Tabler, Phosphor. Cada una tiene un "tono" distinto.

10. **Performance constraints** — si los setters usan laptops viejas / conexión lenta, el rediseño tiene que ser liviano. Si tienen máquinas nuevas, podemos darle más glow.
