Forma de `lead.commitment` (D-01, objeto único, plano en el lead):

  tipo       string  — uno de COMMITMENT_TIPOS
  parte      string  — 'yo' | 'prospecto'
  canal      string  — uno de NEXT_ACTION_CANALES ('llamada'|'whatsapp'|'email'|'')
  dueAt      string  — ISO
  estado     string  — 'pendiente' | 'cumplido' | 'incumplido' | 'vencido'
  motivo     string  — texto libre del SDR, <= 200 chars
  callId     string  — ts del callLog entry que lo originó, o ''
  createdAt  string  — ISO
  createdBy  string  — nombre del actor, <= 80 chars
  closedAt   string  — ISO al cerrar, '' mientras pendiente
  closedBy   string  — nombre de quien cerró, '' mientras pendiente

`closedAt`/`closedBy` son una extensión ADITIVA sobre la lista de D-01: D-11
(historial de compromisos cerrados en el timeline del lead) necesita una fecha
de cierre para ubicar el evento. No se quita ningún campo de D-01.

Firmas públicas (todas expuestas en `globalThis.__voiceAgent`):

  _sanitizeCommitment(raw) -> {tipo, parte, canal, motivo, dueAt} | null
  _commitmentDueAtForTipo(tipo, nowIso) -> string ISO
  _commitmentNextActionTipo(parte, tipo) -> 'esperar_respuesta'|'enviar_info'|'callback'
  _commitmentMotivo(commitment) -> string
  _commitmentEffectiveEstado(commitment, nowMs) -> 'pendiente'|'vencido'|'cumplido'|'incumplido'
  _setCommitment(lead, spec, nowIso) -> commitment | null   (muta lead)
  _closeCommitment(lead, estado, nowIso, closedBy) -> commitment | null   (muta lead)
