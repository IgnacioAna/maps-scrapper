```js

  // picker de setup del grupo de reportes. Es unreadChats() SIN el filtro de
  // badge de no-leído: mismos selectores, cero scraping nuevo.
  allChats() {
    const out = [];
    const items = document.querySelectorAll('[data-testid="cell-frame-container"], div[role="listitem"]');
    let i = 0;
    for (const item of items) {
      const nameEl = item.querySelector("span[title]") || item.querySelector('div[role="gridcell"] span[dir="auto"]') || item.querySelector('span[dir="auto"]');
      const name = (nameEl?.getAttribute("title") || nameEl?.textContent || "").trim();
      if (!name) continue;
      out.push({ index: i++, name });
      if (out.length >= 40) break;
    }
    return out;
  },
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DOM de WhatsApp Web → overlay del picker | los nombres de chat son texto de terceros que se pinta dentro de la propia página |
| npm registry → artefacto que corre en la máquina del user | `npx @electron/asar` descarga una herramienta al vuelo y con ella se arma el binario |
| binario nuevo → sesión de WhatsApp del número dedicado | un asar mal empaquetado deja la app sin arrancar o con código viejo |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-29 | Tampering (XSS en el propio contexto) | overlay del picker | mitigate | las filas se construyen con `createElement` + `textContent`; nunca `innerHTML` con el nombre del chat. Un chat llamado `<img onerror=...>` no ejecuta nada |
| T-21-30 | Tampering (supply chain) | `npx @electron/asar` | mitigate | se fija el major (`@electron/asar@3`) y se hace backup del asar anterior ANTES de tocar nada; la verificación del paso 7 re-extrae y grepea el resultado, así que un pack corrupto se detecta en el acto |
| T-21-31 | Denial of service | repack sobre la carpeta v0.5.10 | mitigate | se trabaja sobre una COPIA (`v0.5.11`); `v0.5.10` queda intacto como rollback inmediato, además del `.bak` del asar |
| T-21-32 | Information disclosure | el picker lista todos los chats del número | accept | es el número dedicado (D-07), en la máquina del user, dentro de su propia sesión de WhatsApp. La lista no sale del proceso: al server solo viaja el nombre del chat ELEGIDO |
