```
GET /api/setters/dial-sessions?setter=&limit=&all=
  200 → { setterId: string|null, sessions: [ {…sesión…} ], total: number }
  403 → { error } fuera de scope
  · orden: startedAt descendente (la más reciente primero)
  · limit: default 20, tope 100
  · por defecto NO lista el ruido (0 marcadas y menos de DIAL_SESSION_NOISE_MAX_S

  200 → { session }
  400 → { error } si el mood no está en la whitelist
  404 → { error } si el id no existe DENTRO del scope del que pide
```
